# simple-posts

Простой учебный сайт на Python и Flask. Можно зарегистрироваться, войти и публиковать посты, которые видят все посетители. 

Текущая версия: **1.0.0**. Что менялось между версиями, написано в [CHANGELOG.md](CHANGELOG.md).

## Что умеет сайт

- регистрация по логину и паролю;
- вход и выход;
- публикация постов (только для вошедших пользователей);
- просмотр всех постов (для всех, даже без входа);

## Что нужно для запуска

- **Python 3.8 или новее.** Проверить версию можно командой `python --version` (на macOS и Linux иногда `python3 --version`). Скачать Python: https://www.python.org/downloads/
- **Git**, чтобы скачать проект. Скачать Git: https://git-scm.com/downloads



## Установка

### 1. Склонировать проект

```
git clone https://github.com/USERNAME/simple-posts.git
cd simple-posts
```

### 2. Создать виртуальное окружение

Windows:

```
python -m venv venv
venv\Scripts\activate
```

macOS и Linux:

```
python3 -m venv venv
source venv/bin/activate
```

Если всё получилось, в начале строки терминала появится `(venv)`.

### 3. Установить зависимости

```
pip install -r requirements.txt
```



## Запуск

```
python app.py
```

В терминале появится что-то такое:

```
 * Running on http://127.0.0.1:5000
```

Откройте в браузере адрес http://127.0.0.1:5000. Чтобы остановить сайт, нажмите в терминале `Ctrl + C`.

При первом запуске рядом с `app.py` сам создастся файл `database.db`. Это и есть база данных.

## Как пользоваться

1. Нажмите **Регистрация**, придумайте логин и пароль.
2. После регистрации откроется страница **Вход**. Введите тот же логин и пароль.
3. На главной странице появится поле для текста. Напишите что-нибудь и нажмите **Опубликовать**.
4. Пост появится в списке **Все посты**. Новые посты показываются сверху.
5. Чтобы выйти, нажмите **Выйти**.


## Как это устроено

### Страницы

| Адрес | Что делает |
|---|---|
| `/` | Главная: список всех постов и форма для нового поста |
| `/register` | Регистрация |
| `/login` | Вход |
| `/logout` | Выход |
| `/add` | Сюда отправляется форма нового поста |


### База данных

Используется SQLite, вся база лежит в одном файле `database.db`. В ней две таблицы.

Таблица `users`:

| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER | номер пользователя |
| username | TEXT | логин, не может повторяться |
| password | TEXT | хэш пароля |

Таблица `posts`:

| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER | номер поста |
| username | TEXT | логин автора |
| text | TEXT | текст поста |



### Авторизация

Когда пользователь входит, его логин сохраняется в сессии (`session["username"]`). Сессия хранится в cookie браузера и подписана секретным ключом `app.secret_key`, поэтому подделать её нельзя. Если в сессии есть логин, значит пользователь вошёл.

### Безопасность

- Пароли хранятся не в открытом виде, а в виде хэша (`generate_password_hash`, `check_password_hash`). Даже если кто-то украдёт базу, паролей он не увидит.
- В SQL-запросах значения подставляются через `?`, а не склеиваются в строку. Это защищает от SQL-инъекций.
- Логины и тексты постов выводятся через `escape()`. Поэтому если кто-то напишет в посте HTML или JavaScript, он покажется как обычный текст и не выполнится.

> Это учебный проект. Перед тем как выкладывать его в интернет, обязательно замените `app.secret_key` на свою длинную случайную строку и выключите `debug=True`.
