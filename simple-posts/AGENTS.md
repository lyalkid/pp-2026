# AGENTS.md

Инструкция для ИИ-ассистентов (Claude, ChatGPT, Copilot, Cursor и т.д.), которые работают с этим проектом. Для людей есть README.md.

## Кратко о проекте

Учебный веб-сайт: регистрация, вход, публичные посты, два языка интерфейса (ru, en).
Стек: Python 3, Flask, sqlite3 (стандартная библиотека), werkzeug.security.
Весь код в одном файле `app.py`. Шаблонов, CSS, JavaScript нет.

## Запуск

```
pip install flask
python app.py
```

Сайт на http://127.0.0.1:5000. Таблицы создаёт функция `init_db()` при запуске.

## Структура app.py (сверху вниз)

1. `texts` — словарь переводов `{язык: {ключ: фраза}}`.
2. `t(key)` — возвращает фразу на языке из `session["lang"]` (по умолчанию `"ru"`).
3. `lang_links()` — HTML ссылок переключения языка.
4. `/lang/<code>` — сохраняет язык в сессию, возвращает на прошлую страницу.
5. `get_db()`, `init_db()` — работа с SQLite.
6. Маршруты: `/`, `/register`, `/login`, `/logout`, `/add`.

## Схема базы

```sql
CREATE TABLE users (id INTEGER PRIMARY KEY AUTOINCREMENT, username TEXT UNIQUE, password TEXT);
CREATE TABLE posts (id INTEGER PRIMARY KEY AUTOINCREMENT, username TEXT, text TEXT);
```

`password` хранит хэш, не пароль. `posts.username` — строка логина, не внешний ключ.

## Сессия

- `session["username"]` — логин вошедшего пользователя. Если ключа нет, пользователь не вошёл.
- `session["lang"]` — выбранный язык.

## Правила для изменений кода

Проект намеренно написан как код начинающего программиста. Сохраняй этот стиль.

- Всё в одном файле `app.py`. Не разбивай на модули и пакеты.
- HTML собирается строками через `+`. Не добавляй Jinja-шаблоны, `render_template`, CSS, JavaScript.
- Не добавляй новые библиотеки (ORM, Flask-Login, Flask-Babel, WTForms). Только Flask и стандартная библиотека.
- Не используй классы, декораторы кроме `@app.route`, type hints, f-строки в сложных местах. Простой понятный код.
- Каждый маршрут сам открывает и закрывает соединение с базой (`get_db()` ... `conn.close()`).

## Обязательно соблюдать

- Любая новая надпись интерфейса — через `t("ключ")`. Ключ добавить во ВСЕ языки в `texts`. Не писать текст прямо в HTML.
- Любые данные пользователя (логины, посты) выводить через `escape()`.
- SQL-запросы только с параметрами `?`. Никогда не подставлять значения в строку запроса.
- Пароли только через `generate_password_hash` / `check_password_hash`.
- Действия, которые требуют входа, проверяют `if "username" not in session: return redirect("/login")`.
- Каждая страница начинается с `html = lang_links()`.

## Как добавить язык

1. Добавить в `texts` блок с новым кодом языка и всеми теми же ключами, что у `"ru"`.
2. Добавить ссылку в `lang_links()`.

## Как проверить после изменений

1. `python app.py` запускается без ошибок.
2. Регистрация нового пользователя, вход, публикация поста, выход работают.
3. Переключение RU/EN меняет все надписи на всех страницах.
4. Пост с текстом `<b>test</b>` показывается как текст, а не жирным.
