# Как помочь проекту

Спасибо, что хотите помочь! Этот проект учебный, поэтому здесь рады и новичкам. Если что-то непонятно, смело задавайте вопрос в Issues.

## Чем можно помочь

- сообщить об ошибке;
- предложить идею;
- исправить опечатку в тексте или документации;
- добавить перевод на новый язык;
- добавить новую функцию.

## Сообщить об ошибке или предложить идею

Откройте вкладку **Issues** на GitHub и нажмите **New issue**. Опишите:

- что вы делали;
- что ожидали увидеть;
- что произошло на самом деле;
- версию Python и операционную систему.

## Как внести изменения

### 1. Сделайте fork

Нажмите кнопку **Fork** вверху страницы репозитория. У вас появится своя копия проекта.

### 2. Скачайте свою копию

```
git clone https://github.com/ВАШ_ЛОГИН/simple-posts.git
cd simple-posts
```

Установите и запустите проект по инструкции из [README.md](README.md).

### 3. Создайте ветку

Не работайте прямо в ветке `main`. Создайте свою ветку с понятным названием:

```
git checkout -b add-german-language
```

### 4. Внесите изменения

Правила, которые важно соблюдать:

- **Код остаётся простым.** Всё в одном файле `app.py`, без шаблонов, стилей и новых библиотек. Проект специально написан как код начинающего программиста.
- **Все надписи через `t()`.** Новый текст на странице добавляйте в словарь `texts` сразу для всех языков, а в коде пишите `t("ключ")`.
- **Данные пользователя через `escape()`.** Всё, что ввёл пользователь, выводится через `escape()`.
- **SQL только с `?`.** Никогда не склеивайте значения в строку запроса.

### 5. Проверьте, что всё работает

Запустите `python app.py` и проверьте руками:

- регистрация нового пользователя;
- вход и выход;
- публикация поста;
- переключение RU / EN на всех страницах.

### 6. Запишите изменение в CHANGELOG

Откройте [CHANGELOG.md](CHANGELOG.md) и в раздел `## [Unreleased]` добавьте строчку о своём изменении в нужную группу:

- `### Added` — добавили новое;
- `### Changed` — изменили существующее;
- `### Fixed` — исправили ошибку;
- `### Removed` — удалили.

Пример:

```
## [Unreleased]

### Added
- Немецкий язык интерфейса.
```

Номер версии ставить не нужно, это делается при выпуске релиза.

### 7. Сделайте коммит

Пишите понятное сообщение, что сделано:

```
git add .
git commit -m "Add German language"
git push origin add-german-language
```

### 8. Откройте Pull Request

Зайдите на страницу своего fork на GitHub. Там появится кнопка **Compare & pull request**. Нажмите её, опишите, что вы сделали и зачем, и отправьте.

После этого автор проекта посмотрит изменения, может задать вопросы или попросить что-то поправить. Когда всё хорошо, изменения попадут в проект.
